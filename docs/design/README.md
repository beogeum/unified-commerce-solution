# 화면 시안 (M1~M7)

- 76개 화면 시안. `canvas.json`이 화면 배치·제목 목록이고, 화면 하나가 `*.dc.html` 파일 하나다.
- 모든 숫자는 **예시 데이터**다. 화면 간 숫자(예: 10월 순매출 620,000,000원 · 공헌이익 129,000,000원, AMP-30 판매가능 513개)는 서로 맞도록 계산해 두었다.
- 시안에 표시된 정책값은 `docs/11-decisions-and-open-questions.md` §A(사용자 확정)·§H(위임 결정)를 따른다.
- 파일은 디자인 캔버스용 형식(`<x-dc>`, `support.js`)이라 브라우저에서 단독으로 열면 스타일 일부만 보인다. 캔버스 보기는 Claude 아티팩트(비공개, 소유자 공유 필요)에서 한다.
- 2026-11-21 이후 추가된 35개 화면은 `tools/mockup-gen/`의 생성 스크립트로 만들었다(`python3 tools/mockup-gen/gen.py`). 스크립트는 메뉴 링크를 다시 연결하고 깨진 링크를 검사한다.
